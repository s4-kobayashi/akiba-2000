# 秋葉原 2000

バスケットコートがあったころ(2000 年初夏の昼)の秋葉原駅前を、ブラウザの中で歩ける 1 人用の空間です。

HTML は VRChat 本体へアップロードできないので、VRChat に似た操作をブラウザで再現しました。三人称の視点、頭上のネームプレート、エモート、地図からの移動があります。

**写実の到達点:** 実在の街路として読める水準ですが、写真と見間違える水準ではありません。独立監査の判定は総合「部分的」です(詳細は「写実の到達点と限界」)。

## 起動

[uv](https://docs.astral.sh/uv/) が必要です。プロジェクトのフォルダで次を実行します。

```bash
uv run --no-project python tools/serve.py 9181 .
```

ブラウザで <http://127.0.0.1:9181/> を開きます。WebGL2 が必要です。外部へのリクエストは無く、素材とライブラリはすべて同梱しています(フォルダ全体で約 97MB)。

次の 2 つの方法では動きません。

- `index.html` を直接開く: `file://` では ES module と素材を読めません。
- `python -m http.server` で配信する: Windows では `.js` が `text/plain` で返り、モジュールの読み込みが失敗します。

## 操作

| 入力 | 動作 |
|---|---|
| WASD | 歩く |
| Shift | 走る |
| マウス | 見回す(ポインタロックが使えないときはドラッグ) |
| Space | ジャンプ |
| V | 一人称と三人称の切り替え |
| 1 / 2 | 手を振る / シュートのエモート |
| クリック / F | ボールを投げる(コートのボールに近づくと拾う) |
| M | 地図と史実メモ。地図から各地点へ移動できる |

タッチ操作(左で移動、右で視点)と、対応端末での「VR で入る」ボタンも実装しています。ただし実機では確認していません。

URL の末尾に `?q=high` を付けると AO を固定し、`?q=low` を付けると低い解像度から始めます。指定しなければ GPU の余力で自動調整します。

## 歩ける範囲

- 駅前広場: 青と黄の大コート、円形コート、3on3 をする人たち
- 電気街口の駅前道路: 路上駐車、赤レンガの歩道、自転車
- 中央通り(北から南へ): 看板の並ぶビル街
- 総武線のガード下と南の裏通り、東の高架沿い
- 青果市場跡の駐車場

高架を黄・黄緑・青の電車が走ります。動きを減らす設定(reduced-motion)では電車と通行人が止まります。

## 写実の到達点と限界

追補を含む版を独立監査にかけた判定です。

| 問い | 判定 |
|---|---|
| 写真と見間違えるか | 未達 |
| 実在の街路として歩いて没入できるか | 部分的 |
| 「リアルな空間」を満たしたか | 部分的 |
| 総合 | 部分的 |

監査の後に、広場の地面の粒と汚れ、下地の色、遠景ビルの後退階とアンテナを足しました。この分は監査に回していません。判定を変える規模の変更ではないと考えていますが、これは私の推定です。

残っている差は影響の大きい順に次のとおりです。

1. **車:** 近くでは低ポリの塊に見えます。三角形の予算内では写真の域に届かず、外部モデルが要ります。
2. **人物:** 顔と服のしわはテクスチャで描きましたが、近くではマネキンです。これも外部モデルが要ります。
3. **広場の手前:** 粒と汚れを足しましたが、広く単調に見えます。写真より広く見える原因が距離か画角かは未確定です。
4. **遠景のビル:** 窓の並んだ箱に見えます。
5. **樹木と街路の細部:** 葉のカードは近くで分かります。路上の物も写真より少なめです。

Poly Haven の 521 モデルに人物は無く、車は `covered_car` だけでした。Sketchfab と Poly Pizza は確認していません。

## 史実と権利

- コートの開設(1993 年 9 月)と閉鎖(2001 年 7 月 31 日)は SNS の投稿によるもので、公的資料は確認できていません。区分と出典は [SOURCES.md](SOURCES.md) にあります。
- 建物の位置と奥行き、広場の寸法は写真からの目測です。人物、車の配置、棚の商品は創作です。
- 看板は当時の実名を文字組みで置いており、ロゴは模写していません。**実名を使っているので私的利用が前提です。** 外部公開するなら別途判断が要ります。
- テクスチャと空は Poly Haven の CC0、描画は three.js r171(`vendor/three/LICENSE`)です。参照した当時の写真は同梱していません。

## 検証の結果

Playwright で実測した値です。fps は別プロセスが GPU を使っていない保証が無く、参考値です。

| 項目 | 結果 | 使ったスクリプト |
|---|---|---|
| 描画負荷(描画命令/三角形) | 駅前 63/247,771、コート 60/237,907、中央通り 65/242,515 | `tools/refview.js` |
| fps(AMD Radeon 内蔵 GPU) | 60.2 | `tools/shoot.js` |
| 歩行 | 14 区間すべて到達、落下なし、外周から出られない | `tools/walk.js` |
| 操作 | 歩行、V、エモート、ジャンプ、ボール、地図移動が動く。エラー 0 | `tools/ops.js` |
| 横あふれ | 1440 / 768 / 390px で `scrollWidth` が画面幅と一致 | `tools/checks.js` |
| その他 | reduced-motion で停止、WebGL 不可時の案内、外部リクエスト 0 | `tools/checks.js` |

`walk.js` と `ops.js` は、最後のアンテナの修正の 1 つ前の版で実行しました。この修正は歩けない遠景の見た目だけを変えます。

**未確認:** 実機の WebXR、実際のポインタロック(Playwright では取れず、ドラッグ視点で確認)、タッチ操作、シュートのエモートとクリック投げの実入力、他のプロセスが GPU を使っていないときの fps。

## 既知の不具合

`js/buildings.js` の遠景の屋上面と塔屋は、`roof` バッチの確定後に追加しているので描画されていません。直すと三角形が約 5,000 増えて、自分で決めた予算の 25 万を超える見込みです(個数からの概算)。
